# CLASE10

## Tema y objetivo del día

- **Tema:** Fundamentos de las consultas HTTP aplicadas al CRUD mediante fetch.
- **Fecha:** Jueves 12 de marzo de 2026.
- **Horario:** 16:30 - 18:00.
- **Objetivo:** Comprender la estructura fundamental de una petición HTTP (URL, método, headers, body y respuesta) y cómo se aplica al desarrollo de operaciones CRUD en aplicaciones web.


## Resultados de aprendizaje de la sesión

- Comprensión profunda de las consultas HTTP:
Aprendimos que la base de la comunicación entre frontend y backend se construye mediante peticiones HTTP, entendiendo sus cinco partes fundamentales: URL, método, headers, body y respuesta del servidor.

- Relación entre protocolo HTTP y desarrollo web:
Comprendimos que, aunque cambie el lenguaje de programación, la estructura de una petición HTTP se mantiene, lo que permite trasladar el mismo conocimiento entre distintos entornos tecnológicos.

- Uso de fetch para interactuar con APIs:
Analizamos cómo las peticiones HTTP se implementan en JavaScript mediante fetch, conectando la lógica del frontend con los endpoints del backend.

- Comprensión conceptual del flujo de actualización de datos (update):
Revisamos la lógica necesaria para actualizar recursos mediante PATCH, comparando los datos originales con los datos editados para enviar únicamente los cambios al servidor.

## Conocimientos adquiridos en con los ejercicios de la sesión

Durante esta sesión reforzamos los cimientos conceptuales que sostienen cualquier aplicación web conectada a una API.

Finalmente, se revisó la guía conceptual para implementar la funcionalidad de actualización (update) dentro del CRUD de recetas. Se explicó el flujo lógico necesario para modificar datos existentes.
