Hice que cada restaurante mostrase también sus recetas y comentarios. Para ello, primero creé interfaces en Angular (Receta y Comentario) para tener bien definida la estructura. Después hice servicios que llaman a la API para obtener las recetas y comentarios según el id del restaurante. En el componente de restaurante, cogí ese id desde la URL con ActivatedRoute y, con él, cargué tanto el restaurante como sus recetas y comentarios. Finalmente, en el HTML los mostré con *ngFor usando tarjetas, consiguiendo que cada restaurante enseñe solo sus recetas y comentarios correspondientes de forma dinámica.
